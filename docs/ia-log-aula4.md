# Registro de IA — Aula 4

Este registro descreve a configuração original da Aula 4. A [configuração final](parte4.md) separa o processamento de capas em uma segunda Lambda.

Usamos o Codex para ajudar a revisar o enunciado, adaptar o código da Aula 3 e conferir a implantação na AWS Academy. O grupo manteve a arquitetura simples: uma Lambda para a API e o evento do S3, MySQL no RDS, página estática na EC2. O teste final incluiu CRUD, relatório e envio de capa. Os integrantes devem revisar o código e explicar cada serviço na apresentação.
