## Como colocar no GitHub

1. Extrair o ZIP em uma pasta.
2. No GitHub, escolher **New repository**, informar um nome (sugestão: `biblioteca-simples-projeto2`) e criar o repositório. Não há link criado por esta entrega.
3. Escolher **Add file → Upload files** e arrastar o conteúdo da pasta, mantendo `README.md`, `specs/` e `docs/` na raiz. Confirmar o envio em **Commit changes**.
4. Após obter o usuário do professor, convidá-lo em **Settings → Collaborators** (ou na opção de acesso equivalente da conta). Conferir se o convite foi aceito.
5. Revisar os documentos com Copilot usando o prompt de `docs/ia-log.md`; registrar sugestões e decisões reais do grupo.
6. Copiar o endereço do repositório e enviá-lo no Moodle. Nada foi enviado automaticamente ao professor ou ao Moodle.
