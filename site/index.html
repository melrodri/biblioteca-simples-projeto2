Biblioteca Simples

Catálogo de autores e livros para pequenas bibliotecas, com capas e relatório de livros por autor.

Projeto 2 — Serviços em Nuvem

O que o sistema faz

Autores

Cadastrar, consultar, editar e excluir autores.

Livros

Cadastrar livros ligados a um autor, com título e ano.

Capas

Enviar a capa de cada livro; os dados da imagem são registrados automaticamente.

Relatório

Ver quantos livros cada autor tem no catálogo.

Tecnologias

EC2 e VPC

Site em uma instância pequena na subnet pública.

Amazon S3

Armazenamento privado das capas.

API Gateway + Lambda

API do cadastro e do relatório.

Amazon RDS

Banco de dados MySQL em rede privada.
